macOS平台Clash Verge与Surge客户端配置指南

更新时间：2026-11-18 适配平台：macOS 难度等级：入门新手 阅读时长：6 分钟阅读
Mac 芯片适配提示：下载客户端时请注意区分处理器架构：Apple Silicon 芯片（M1/M2/M3/M4 系列）请下载 aarch64 / arm64 版本；Intel 老款机型请下载 x64 版本。

一、首选客户端推荐

  • Clash Verge Rev for macOS (免费开源)：界面现代，完美适配 macOS 暗黑模式，支持 Enhanced Mode（增强模式 Tun）。
  • Surge 5 for Mac (专业收费)：功能极为强悍的网络调试神器，支持精细抓包与设备网络接管。

二、Clash Verge Rev 配置步骤

步骤 1：安装与初次权限设置

打开 dmg 镜像，将 Clash Verge 图标拖入 Applications 应用程序文件夹。首次启动若提示“无法打开，因为 Apple 无法检查其是否包含恶意软件”，请打开 系统设置 → 隐私与安全性，在安全性下方点击 仍要打开。

步骤 2：导入订阅与启用

  1. 在“订阅”界面粘贴订阅 URL 并下载配置。
  2. 在“代理”界面选择“规则”模式，点选可用节点。
  3. 在“设置”中勾选 系统代理。

三、配置 Terminal 终端走代理

macOS 系统代理默认不接管终端（zsh/bash）的网络请求。如需让 git clone 或 curl 走代理，请在 ~/.zshrc 中追加：

alias setproxy="export http_proxy=http://127.0.0.1:7890; export https_proxy=http://127.0.0.1:7890"
alias unsetproxy="unset http_proxy; unset https_proxy"

执行 source ~/.zshrc 后，在终端输入 setproxy 即可让命令行秒速连接外网。
