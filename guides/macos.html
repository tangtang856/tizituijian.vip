macOS系统Clash与Surge客户端配置指南

更新时间：2026年11月 栏目：客户端配置图文指引 适配系统：全平台支持
教程速览：macOS 用户推荐使用开源免费的 Clash Verge Rev for Mac，原生适配 Apple Silicon (M系列芯片) 与 Intel 架构；若预算充裕追求极致网络调优，可选择专业的商业软件 Surge for Mac。

一、Clash Verge Rev for Mac 安装

  1. 根据您的 Mac 芯片类型下载对应安装包：
    • aarch64.dmg：适用于 M1 / M2 / M3 / M4 系列芯片的 Mac。
    • x64.dmg：适用于老款 Intel 芯片的 Mac。
  2. 打开 DMG 安装包，将应用图标拖动到 Applications (应用程序) 文件夹中。
  3. 首次打开如提示“来自未知开发者无法打开”，请前往系统设置 → 隐私与安全性 → 找到提示并点击“仍要打开”。

二、配置订阅与代理

  1. 打开 Clash Verge Rev，进入 订阅 (Profiles) 页面。
  2. 粘贴您的专属订阅 URL，点击 下载 (Download)。
  3. 选中已下载的配置卡片，使其高亮生效。
  4. 进入 设置 (Settings)，打开 系统代理 (System Proxy) 开关。
  5. 在状态栏图标或代理页面选择需要的节点（如香港、日本线路）。

三、终端（Terminal）与开发环境代理配置

macOS 系统的终端默认不继承系统 GUI 代理。若在终端中使用 git 或 curl 需要代理，可在终端运行：

export http_proxy=http://127.0.0.1:7897
export https_proxy=http://127.0.0.1:7897

或者直接在 Clash Verge Rev 设置中开启 Tun 模式，全局接管所有命令行流量。
