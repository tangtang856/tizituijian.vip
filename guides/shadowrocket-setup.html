神器定位：Shadowrocket（俗称小火箭）是 iOS 平台上性价比最高、普及率最广的代理客户端，售价仅 $2.99 美元，支持几乎所有主流加密协议。

一、三种添加节点的核心方法

  1. 订阅链接自动同步（最推荐）：点击右上角 + → 类型选择 Subscribe → 粘贴 URL 并备注服务商名称。
  2. 扫描屏幕二维码：点击左上角扫描图标，直接对准电脑屏幕上的节点二维码完成添加。
  3. 从剪贴板一键读取：复制 ss://、vmess:// 或 trojan:// 链接后打开小火箭，软件会自动提示导入。

二、三种全局路由模式详解

  • 配置 (Config)：智能分流模式。遇到国内网站走 Direct 直连，遇到国外被封网站走 Proxy 代理，日常使用必备。
  • 代理 (Proxy)：全局代理模式。无论访问国内还是国外网站均走海外节点，适合调试。
  • 直连 (Direct)：相当于关闭代理通道，所有网络走本地原生物理宽带。

三、小火箭定期自动更新订阅设置

进入 设置 → 订阅，勾选 “打开时更新” 与 “自动后台更新”，确保节点 IP 变更时小火箭能无感同步最新线路。
