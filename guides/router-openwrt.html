OpenWrt软路由PassWall与OpenClash全屋科学上网教程

更新时间：2026-11-18 适配平台：软路由 难度等级：高级进阶 阅读时长：10 分钟阅读
软路由优势：在家庭网络主路由部署科学上网后，局域网内的所有手机、电脑、智能电视、游戏主机无需安装任何客户端，即可自动享受海外网络加速。

一、OpenClash 与 PassWall 选型对比

对比维度 OpenClash PassWall
底层核心 Clash Premium / Mihomo (Meta) Xray / Sing-box / Trojan-Go

内存硬件消耗 偏高（建议 512MB 以上运存） 较低（适合轻量级路由器）

二、OpenClash 核心配置步骤

1. 模式选择

进入 OpenClash 插件设置，推荐选择 Fake-IP (TUN) 模式。该模式在软路由层级拦截 DNS 请求，无需向上游等待 DNS 解析即可直接建立连接，大大降低网页首屏载入延迟。

2. 配置文件订阅与导入

在“配置文件订阅”选项卡中添加机场订阅链接，勾选“自动更新”并设定每天凌晨 4 点定时更新订阅。

3. DNS 防污染与国内分流

开启“本地 DNS 劫持”，国内 DNS 设置为运营商 DNS 或 223.5.5.5，海外 DNS 选择 https://1.1.1.1/dns-query，彻底规避 DNS 污染风险。
